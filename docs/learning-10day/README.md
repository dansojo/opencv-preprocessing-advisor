# 10일 OpenCV 심화 학습 과정

이 과정은 OpenCV 전처리와 이미지 분류 프로젝트를 코드, 실험, 설명으로 연결하는 Notion 포트폴리오용 심화 학습 경로입니다. 과정을 마치면 프로젝트의 문제, 선택한 API, 검증 결과와 한계를 자신의 말로 설명할 수 있습니다.

시작하기 전에 [합성 타일 샘플](../../data/samples/synthetic-tile.png)을 준비하세요. 각 Day의 실험은 이 공개 가능한 샘플 또는 사용자가 준비한 이미지로 수행합니다.

## 순서와 의존성

Day 1에서 이미지 데이터와 색 공간의 기본을 확인한 뒤, Day 2의 상태 진단으로 입력 품질을 판단합니다. Day 3~5의 전처리와 형상 처리를 거쳐 Day 6에서 파이프라인과 추천 점수를 연결하고, Day 7~9에서 특징·분류·재현성 평가를 쌓습니다. Day 10은 앞선 결과를 포트폴리오 설명과 실전 대응으로 통합합니다.
